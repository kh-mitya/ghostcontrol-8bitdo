Buttons

This controller uses the Switch protocol (8BitDo adapter or Switch Pro): LT and RT are on / off only, without analog travel.

Shortcuts on the controller

  • Xbox + RB / Xbox + LBNext / previous profile. A notification shows its name.
  • Xbox alonePS button (tap or hold).
  • View + Menu togetherTouchpad click (can be turned off in Sticks & triggers).

8BitDo adapter (hold 3 seconds)

  • View + LBSwitch mode, the one this payload uses.
  • LB + RB + L3 + R38BitDo Ultimate Software profile on / off.
  • View + ↑ / ← / → / ↓Other adapter modes (XInput, DInput, Mac, PS Classic). The controller stops working here until you switch back with View + LB.

How it works

  • ProfilesShared by all controllers; every controller remembers its own. Buttons are kept by position, so a profile works the same on Xbox and Switch layouts.
  • DefaultBuilt in and cannot be changed. Save your changes as a new profile.
